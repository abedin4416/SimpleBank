This is a simple practice banking system repository. Initially it looks unusable and naive.
The idea is core bank.cpp is a backend logic that will be called and used by web services.
Accounts data will be on server and users cannot directly access them without proper verfication.
You can edit this repository if you can improve it.

bank.cpp is the main c++ file for this system.
json.hpp is the header file containing the logic of storing json data in a file named data.json.
bank.cpp can be compiled using command "g++ bank.cpp -o bank" on any platform with gcc installed.
